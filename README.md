## 📥 1. Install the Requirements

Install Termux from a trusted source, then run:

    pkg update && pkg upgrade
    pkg install git clang neovim

Check the installations:

    git --version
    clang++ --version
    nvim --version

## 📦 2. Download This Repository

Go to the directory where you want the project:

    cd ~

Clone the repository from GitHub:

    git clone https://github.com/YOUR_USERNAME/cpp_lesson.git

Enter the downloaded folder:

    cd cpp_lesson

Replace the example URL with your actual GitHub repository URL.

## 📂 3. Access Your Files

Enter the project directory:

    cd ~/c++_lesson

List files and folders:

    ls

Show hidden files and detailed information:

    ls -la

Open the README:

    nvim README.md

Enter a folder:

    cd project

Return to the main repository:

    cd ~/c++_lesson

Find C++ source files:

    find . -type f -name "*.cpp"

## ▶️ 4. Compile and Run a C++ File

Open a source file in Neovim:

    nvim main.cpp

Compile it:

    clang++ -std=c++17 -Wall -Wextra main.cpp -o main

Run it:

    ./main

Replace main.cpp with the name of your actual C++ source file.

## 🔄 5. Update Your Downloaded Repository

Enter the cloned repository:

    cd ~/cpp_lesson

Download the latest changes:

    git pull

## ⬆️ 6. Upload Your Changes to GitHub

From your local repository:

    git add .
    git commit -m "Update C++ lessons"
    git push

GitHub authentication must be configured before pushing.
